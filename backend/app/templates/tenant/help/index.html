{{ 'Filters' if en else 'Φίλτρα' }}

{% if en %} Every number on screen obeys the filters. From / To sets the period; branch, warehouse, channel and series narrow the scope. Clear resets the page when you are not sure what is still active. {% else %} Κάθε αριθμός στην οθόνη υπακούει στα φίλτρα. Το «Από / Έως» ορίζει την περίοδο· υποκατάστημα, αποθηκευτικός χώρος, κανάλι και σειρά περιορίζουν το εύρος. Το «Καθαρισμός» επαναφέρει τη σελίδα όταν δεν είσαι σίγουρος τι είναι ενεργό. {% endif %}

{{ 'The three reading rules' if en else 'Οι τρεις κανόνες ανάγνωσης' }}
{{ '1. Everything is net, excluding VAT' if en else '1. Όλα είναι καθαρά, χωρίς ΦΠΑ' }}

{% if en %} Turnover, purchases, profit and margin are all net. VAT appears only in the document streams, as its own column. The document "Grand Total" is the only figure that includes it. {% else %} Τζίρος, αγορές, κέρδος και περιθώριο είναι καθαρές αξίες. Ο ΦΠΑ εμφανίζεται μόνο στα κυκλώματα παραστατικών, ως ξεχωριστή στήλη. Το «Γενικό Σύνολο» του παραστατικού είναι το μόνο μέγεθος που τον περιέχει. {% endif %}

{{ '2. A period is not a snapshot' if en else '2. Περίοδος ≠ φωτογραφία' }}

{% if en %} Sales, purchases and expenses add up over a period. Stock and customer/supplier balances are a point in time — they do not add up and often do not even respond to From / To. {% else %} Πωλήσεις, αγορές και έξοδα αθροίζονται σε μια περίοδο. Το απόθεμα και τα υπόλοιπα πελατών/προμηθευτών είναι φωτογραφία μιας στιγμής — δεν αθροίζονται και συχνά δεν αλλάζουν καν με το «Από / Έως». {% endif %}

{{ '3. What you see depends on the filters' if en else '3. Ό,τι βλέπεις εξαρτάται από τα φίλτρα' }}

{% if en %} If a number looks wrong, the first things to check are the period and the active filters — then the time of the last sync. {% else %} Αν ένας αριθμός σου φαίνεται λάθος, το πρώτο που ελέγχεις είναι η περίοδος και τα ενεργά φίλτρα — και μετά η ώρα του τελευταίου συγχρονισμού. {% endif %}
